# 위치 측정 품질 개선 검토

검토일: 2026-10-11

이번 변경은 웹앱에서 사용할 수 있는 위치 API와 화면 개선에 한정한다. 실내 평면도, QR코드, 비콘, Wi-Fi RTT, 안드로이드 네이티브 앱 기능은 추가하지 않는다.

## 측정 결과를 고르는 방식

- 일반 지도와 정밀 재측정은 `enableHighAccuracy: true`, `maximumAge: 0`으로 새 위치 갱신을 요청한다. 기본 측정 시간은 최대 15초다.
- 새 요청 이전의 측정값, 오래되거나 미래 시각인 값, 잘못된 좌표·오차값, 중복 시각은 제외한다.
- 직전 위치에서 갑자기 벗어난 값은 바로 적용하지 않는다. 새 위치 주변에서 일관된 측정이 이어지면 실제 이동으로 받아들일 수 있다.
- 오차가 15m 이하인 일관된 측정 두 개가 최소 1초 간격으로 확인되면 일찍 종료할 수 있다. 그렇지 않으면 제한시간 동안 측정한 최근 결과를 비교한다.
- 반환하는 위도·경도, 예상 오차 `accuracy`, 측정 시각 `observedAt`은 실제 기기 측정값이다. 평균 좌표를 만들거나 원본 오차를 임의로 줄이지 않는다. 화면에서는 오차를 올림한 정수로 안내하지만 원의 반경과 서버에 보내는 값은 원본이다.

## 일반 지도와 위치 등록

처음 열리는 일반 지도는 현재 위치를 측정하고, 결과를 확정했을 때 한 번 이동한다. 측정 중 위치·오차 영역은 갱신할 수 있지만 지도를 계속 따라 움직이지 않는다. 하단의 `정밀하게 다시 찾기` 버튼으로 다시 측정할 수 있다.

최근 측정 위치의 예상 오차와 측정 이후 지난 시간을 표시한다. 파란 영역은 해당 측정값의 오차 범위이며, 개인 분석지도의 점선 반경 도구와 구분된다. 오차가 50m를 넘으면 지도를 직접 확인하거나 더 나은 측정 환경에서 다시 찾도록 안내한다.

위치 등록에서 `이 위치 사용`은 좌표와 GPS 출처만 전달한다. 장소 이름이나 제목을 자동으로 채우지 않는다. 직접 위치를 고르거나 장소를 검색한 뒤에는 이전 GPS 콜백이 선택을 덮어쓰지 못한다.

다음 동작은 진행 중인 측정을 취소하고 요청 식별자도 무효화한다.

- 지도 누르기, 끌기, 휠 확대·축소 및 위치 포인트 선택
- 장소 검색창에 포커스하거나 검색하기
- 외부에서 선택 위치·지도 중심·포커스가 바뀌기
- 개인 분석 도구 조작 시작
- 지도 컴포넌트 종료

권한 거부 시 위치 등록 후보와 오차 원을 제거한다. 재시도가 실패한 뒤 남아 있는 기존 측정값은 `이전 측정 위치`와 실제 측정 나이로 표시한다.

## 탐험게임

학생의 위치 공유에는 같은 측정값 필터를 적용하고 캐시 없이 갱신한다. 위치 공유는 기존 동의·게임방 권한에 따라 작동하며 교사 화면에 원본 오차와 측정 시각을 전송한다.

`정밀하게 다시 찾기`와 미션 제출 전에 공통 정밀 측정을 실행한다. 미션 제출은 새 위치가 서버에 반영된 후 진행한다. 정밀 측정과 제출 동안 일반 위치 갱신이 해당 결과를 덮어쓰지 않도록 순서를 맞춘다. 화면이 숨겨지거나 방·권한·공유 상태가 바뀌면 진행 중인 측정과 관련 요청을 중지한다.

미션 반경, 오래된 위치 거부, 오차 허용 기준과 도착 판정은 기존 서버 검증을 유지한다. 측정 품질 개선을 이유로 실내 미션 도착 조건을 느슨하게 바꾸지 않는다.

## 모바일 코드 검토

320~390px 너비의 CSS와 DOM 배치를 검토했다. 이는 실기기에서 GPS 정확도를 검증한 결과나 모든 화면 높이·글꼴 배율의 시각 검증을 의미하지 않는다.

- 검색창은 `min-width: 0`과 가변 폭을 사용한다. 검색·위치 버튼과 같은 줄에서 입력창이 줄어들 수 있다.
- 하단 재측정 버튼은 최소 48px 높이이며 지도 양쪽 여백을 제외한 폭을 넘지 않는다. 360px 이하에서는 글꼴과 좌우 패딩을 줄인다.
- 지도 보기의 안내 스택은 하단 82px에 위치한다. 하단 18px에 있는 재측정 버튼과 공간을 나눈다.
- 오류와 오차 안내를 별도 고정 높이로 겹쳐 배치하지 않는다. 같은 세로 스택에 넣어 긴 안내가 줄바꿈되어도 문서 흐름에 따라 쌓인다.
- 위치 등록의 GPS 확인 카드도 같은 스택 안에 둔다. 높이가 부족할 때 안내 텍스트와 오류 영역을 스크롤할 수 있도록 하고 `이 위치 사용` 버튼은 줄어들지 않도록 한다.
- 오차 안내는 지도의 터치를 가로채지 않는다. 오류 닫기와 GPS 확인 버튼은 별도로 조작할 수 있다.

소프트 키보드가 열린 매우 낮은 지도 영역, 사용자 지정 큰 글꼴, 브라우저별 안전영역 처리는 실제 모바일 시각 검증 대상이다. 일반 지도는 측정값의 원을 제외하면 전체 지도 레이아웃 크기를 바꾸지 않는다.

## 검증 범위와 한계

자동화 검증에는 공통 필터의 잘못된 값·오래된 값·좌표 튐·이동 재포착, 정밀 측정 종료·취소·권한·타이머 정리, 지도에서 늦은 GPS 결과 차단·수동 선택 보존·검색 보존·제목 미삽입·오차 원 정리, 기존 지도 합치기 표시를 포함한다. 게임에서는 원본 좌표·오차·시각 전송, 정밀 측정 뒤 제출 순서, 숨김·공유 중단 이후 요청 취소를 검증한다. 전체 테스트 수와 최종 빌드 결과는 최종 실행 결과에 기록한다.

이 코드는 기존 센서 결과 중 더 신뢰할 만한 값을 선택하고 상태를 명확하게 보여준다. 브라우저의 고정밀 요청은 기기가 반드시 GPS를 사용한다는 보장이 아니며, 실내에서 위치·층·교실을 정확하게 찾는다는 보장도 아니다. 같은 잘못된 위치를 기기가 반복해서 보고하면 일관성 필터만으로 실제 위치를 알아낼 수 없다. 지도 직접 선택은 기록할 위치를 사람이 지정하는 기능이며 기기 센서의 정확도를 높이는 기능은 아니다.

## 최종 실행 결과

- `npm run typecheck`: 통과.
- `npm test -- --maxWorkers=4`: 38개 파일, 349개 테스트 통과. 공통 위치 필터 25개, 지도 GPS UI 11개, 게임 위치 공유·제출 경계 12개를 추가했다.
- `npm run build -- --webpack`: 배포용 컴파일·타입 검사·페이지 생성 통과.
- 로컬 브라우저에서 390px 및 320px 지도 화면을 확인했다. 정밀 측정 중 버튼 중복 클릭이 막히고, 측정 실패 안내와 재측정 버튼이 겹치지 않았다. 320px에서 페이지 가로 폭은 320px로 유지되었고 재측정 버튼 높이는 48px였다.
- 화면 복귀 후 자동 위치 공유 금지, 지연된 재개 성공 무효화, 공유 중지 요청 대기 중 전송 차단, 미션 제출 대기 중 일반 위치 전송 중단을 자동 테스트로 확인했다.

브라우저 검증 환경에서는 실제 위치가 제공되지 않아 측정 대기·실패·재시도 화면을 확인했다. 실제 건물 내부의 위치 오차 감소는 이번 검증 결과에 포함하지 않는다.
