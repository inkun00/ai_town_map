# 2단계 완료 검토 — 모바일 UX와 화면 골격

작성일: 2026-09-27 · 기준: [PRD 1.3](PRD.md), [개발 계획](DEVELOPMENT_PLAN.md)

## 구현 결과

- Next.js·React·TypeScript 기반 모바일 우선 시안을 구현했다. 실행: `npm install`, `npm run dev`, `http://localhost:3000`.
- 홈에서 주제·지역·제목으로 지도를 찾고, 5단계 개설 흐름에서 주제를 먼저 선택한다. 기본 정보, 주제별 유형·이모지·평가색, 참여 범위, 최종 미리보기를 확인할 수 있다. 직접 만들기에서는 분류·대표 이모지와 핀 색상 방식(단색·유형별·평가별)을 고른다.
- 지도 화면은 예시 배경 위에 주제별 이모지 핀을 표시한다. 유니버설 디자인·안전은 평가 결과로 핀 색을 정하고, 생태·날씨생활은 관찰 유형으로 색을 정한다. 날씨의 생활 영향 평가는 상세 기록에서 별도로 보여준다. 필터·목록·상세 바텀시트를 조작할 수 있다.
- 3단계 기록 흐름에서 위치, 제목, 유형, 이모지, 주제별 평가·질문, 설명, 사진 선택, 링크, 개선 아이디어를 입력한다. 필수 질문과 링크 형식을 확인한다. 완료한 기록은 화면 내 지도·상세·기본 통계에 반영된다.
- 유니버설 디자인 질문에는 이동편의성·정보 접근성·소리 안내 여부·휴식공간 여부·안전성을 아이콘과 함께 표시한다. 생태에는 종합 평가가 없고 제안 메뉴도 없다. 댓글과 수동 제안서 초안은 화면 내 상태로 조작할 수 있다.

## 후속 연동 범위

이 단계는 **샘플 데이터 UX 시안**이다. 지도 배경은 직접 그린 SVG이며 카카오맵, GPS, 장소 검색을 연결하지 않았다. Google 로그인·초대 코드·권한 검사·서버·DB·사진 업로드도 아직 없다. 사진은 선택한 파일명만 화면에 보여주며 파일 자체를 보관하지 않는다. 생성한 지도·기록·댓글·제안은 메모리에만 있어 새로고침하면 사라진다. 통계·제안 화면도 실제 서버 집계와 문서 공유 기능은 없다. 초대 전용 예시 지도도 이 단계에서는 권한으로 차단하지 않는다. 해당 기능은 계획의 3~6단계에서 구현·검증한다.

## 다음 단계 안내

3단계는 계정·지도·참여 기반이다. **GPT-6 Sol / High**를 권장한다. 인증·초대·지도별 데이터 격리의 교차 권한 검토에는 **GPT-6 Astra / High**를 권장한다. 완료 기준은 개설자 Google 로그인, 초대 코드·닉네임 참여, 지도·주제 설정의 서버 저장, 다른 기기의 참여 및 서버 권한 검사다. 착수 전에 이 범위와 모델을 다시 안내한다.
