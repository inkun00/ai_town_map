# 6단계 검토 — 통계·수동 제안서

작성일: 2026-09-29

## 구현 결과

- 지도·목록·분석이 하나의 서버 데이터셋을 사용한다. 유형, 종합평가, 한국 시간의 등록일 범위, 선택한 지도 영역, 질문 응답 필터를 동일하게 적용한다. 차트 항목을 누르면 같은 조건의 원본 목록으로 이동한다.
- 게시 기록만 집계한다. 검수 대기·숨김·삭제 기록은 제외하며, 같은 장소의 반복 관찰은 각각 한 건으로 표시한다. 지도 군집을 지역 통계로 사용하지 않는다.
- 유형·종합평가·날짜별 차트, 질문별 응답 분포를 제공한다. 확인 못함·해당 없음·미응답을 유효 분모와 분리하고, 분모 0은 비율 없음으로 표시한다. 질문의 지도 설정 버전별 집계를 분리하며 복수 응답 합계가 100%를 넘을 수 있음을 표시한다. 생태 등 종합평가를 사용하지 않는 지도는 평가 차트를 생성하지 않는다.
- 관리자 CSV 내보내기는 같은 필터의 게시 기록을 사용한다. 작성자 닉네임·장소·정밀 좌표는 기본 제외하고 선택할 때만 포함한다. UTF-8 BOM, 한글 질문 열, 설정 버전과 답변 키, 집계 시각·필터를 포함한다. 스프레드시트 수식으로 실행될 수 있는 셀은 접두 문자로 중화한다. 본문에 직접 적힌 개인정보는 자동 익명화하지 않는다.
- 제안서에 제목·문제·해결안·기대 효과·실천 주체·후속 확인 계획과 최대 30개 근거를 저장한다. 저장 시 서버가 근거 ID·기록 버전·필터·집계 시각·당시 수치를 기록한다. 근거 본문·사진·작성자·정밀 좌표를 스냅샷에 복제하지 않는다.
- 참여자는 초안을 작성·수정·검토 요청하고, 관리자는 확정·수정 요청·공유 중단을 처리한다. 삭제는 작성자 또는 관리자에게 허용한다. 최신 초안과 확정본의 버전을 분리하여 새 초안이 기존 공유본을 덮어쓰지 않는다.
- 제출·확정 시 근거와 집계의 변경 여부를 다시 확인한다. 사진만 변경되어도 관찰 버전을 올려 근거 변경을 감지한다. 공유본에는 변경 안내와 현재 열람 가능한 근거만 표시하며, 숨김·삭제·재검수 근거의 제목·본문·사진은 표시하지 않는다.
- 공유 페이지는 현재 지도 권한을 매번 확인하고 별도의 익명 공개 토큰을 발급하지 않는다. 인쇄 전용 스타일과 브라우저 인쇄/PDF 저장 버튼, 원본 지도 링크를 제공한다. 제안 기능을 끈 지도는 화면과 API 양쪽에서 제안서를 차단한다.
- 제안서 목록은 공개본·본인 작성·검토함·공유 중단함으로 나누고 50건씩 커서로 추가 조회한다. 변경 요청은 CSRF, 낙관적 버전 검사, 생성 요청 중복 방지를 적용한다.

## 구현 범위와 남은 검증

- 지도·목록·통계·CSV는 필터당 최대 10,000건을 처리한다. 초과하면 일부 수치만 보여주지 않고 기간·영역을 좁히라는 오류를 반환한다. 대규모 조사에는 서버 집계와 지도 영역별 페이지 조회를 후속 도입한다.
- CSV는 최초 설계의 비동기 작업 대신 권한을 검사하는 동기 다운로드로 제공한다. 임시 파일·공유 URL을 보관하지 않는다.
- 제안서 action API는 `/actions` 한 경로로 제공한다. 별도 submit/review/unpublish 경로와 임의 과거판 조회 UI는 아직 제공하지 않는다. 현재 확정본과 최신 작업본은 분리하여 보관한다.
- PDF는 브라우저 인쇄를 사용한다. 실제 휴대전화의 PDF 저장·다운로드, 물리적 별도 기기의 Google 개설자/초대 게스트 흐름, GPS·터치 검증은 7단계에서 수행한다. QR 및 카카오 지도 이미지 삽입은 구현하지 않았고 공유 URL·원본 링크를 제공한다.
- 기존 5단계의 댓글·신고·멤버 목록 상한, 30일 경과 삭제 자료의 자동 정리는 계속 운영 과제로 남는다.
- AI 분석은 이 단계에 포함하지 않는다.
