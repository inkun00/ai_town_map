# 주제별 이모지 확장 검증 · 2026-10-01

## 제공 범위

| 주제 | 기존 선택 항목 | 확장 후 선택 항목 |
|---|---:|---:|
| 유니버설 디자인 | 12 | 123 |
| 안전 | 12 | 120 |
| 생태 | 14 | 144 |
| 날씨생활 | 12 | 115 |
| 합계 | 50 | 502 |

수치는 분류별 선택 항목의 합계다. 같은 이모지가 다른 주제나 분류에서 다른 의미로 쓰일 수 있다. 직접 만들기의 모음에는 중복 그림을 합친 293가지가 있으며, 이름·주제·분류로 검색하고 한 분류에 최대 30개를 선택할 수 있다. 대표 이모지를 직접 입력하는 기능도 유지한다.

보행 보조·안내·청각 접근성·생활 시설, 교통·재난·소방·보안, 식물·조류·곤충·수생 동물·서식 환경, 더위·물 고임·강풍·빙판·대기질 등의 요소를 추가했다. 생태 이모지는 관찰 대상을 표현하며 종 판별 결과를 의미하지 않는다.

## 기존 데이터 반영

게시된 v1은 `theme-presets-v1.json`에 보존하고 새 지도는 v2를 사용한다. `RUN_EMOJI_UPGRADE=1 npm run db:expand-emojis`는 트랜잭션으로 활성·보관 상태의 기본 주제 지도에 부족한 선택 항목만 추가한다. 새 설정 revision을 만들고 지도 version·data revision을 갱신한다. 기존 UUID·키·그림·라벨·사용 중지 설정, 평가·질문·기능·핀 색상, 기록과 과거 설정 snapshot은 유지한다. 직접 만든 지도와 삭제 상태 지도는 자동 확장 대상에서 제외한다.

운영 DB에서 기존 지도 2개에 241개 항목을 추가했다. 재실행 결과는 지도 0개·추가 0개로 중복 삽입이 없었다. API v1 정의 조회와 기존 버전으로 지도 만들기도 계속 지원한다.

## 검증

- TypeScript 검사, 테스트 43개, production build 통과.
- API 검사에서 기본 네 주제의 v2 구성 조회 및 새 이모지 기록 저장, v1 조회, 비활성 선택 제한·마지막 활성 이모지 보호, 지도 간 격리·수정 version·사진 처리 통과.
- 직접 만드는 지도는 12개 선택 항목을 가진 분류 생성·조회·마지막 추가 이모지 저장을 검사한다.
- 모바일 390px에서 기본 주제의 25개 목록, ‘약국’ 검색과 선택 상태, 직접 만들기의 293가지 모음 검색과 다중 선택 확인. 가로 넘침 없음.
- 브라우저 확인 과정에서는 사용자 지도에 기록을 제출하지 않았다. API 검사의 합성 지도·기록·계정은 종료 시 정리한다.
