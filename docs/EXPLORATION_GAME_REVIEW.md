# 탐험게임 구현과 검증 (2026-10-02)

## 사용 흐름

1. Google 계정으로 로그인한 지도 개설자 또는 관리자가 운영 중인 지도에 입장합니다.
2. **탐험 가방 → 탐험게임맵 제작**에서 게임 이름과 안내를 입력합니다. 원본의 게시된 포인트 이름·이모지·좌표를 복사하고 원본은 수정하지 않습니다. 승인 대기, 숨김, 삭제 기록과 사진·본문은 복사하지 않습니다.
3. 복사된 포인트에 미션을 설정하거나 게임 전용 포인트를 등록합니다. 객관식·단답형은 서버 자동 채점, 관찰·서술형·현장 체크리스트는 교사 승인 후 점수 지급입니다.
4. 미션별 도착 반경 20~500m, 점수 1~1,000점, 최대 제출 1~10회를 지정합니다. 기본값은 50m, 100점, 3회이며 교사가 변경할 수 있습니다.
5. 게임방을 만들 때 제한시간 1~180분, 최대 학생 1~200명을 설정합니다. 기본값은 30분, 40명입니다. 해당 방의 미션과 정답, 위치, 점수는 방 생성 시 고정됩니다. 이후 제작 화면 수정은 새 방에 적용됩니다.
6. 학생은 메인 **탐험게임** 버튼 또는 공유 링크로 들어가 방 코드, 닉네임, 교사에게 위치 공유 동의로 참여합니다. 학생 Google 로그인은 필수가 아닙니다.
7. 교사가 시작하면 서버 기준 제한시간이 시작됩니다. 학생은 위치 권한을 허용하고 장소 반경 안에서 미션에 응답합니다. 지도와 점수판은 5초 간격으로 갱신합니다.
8. 교사는 학생의 최근 위치·위치 오차·점수와 승인 대기 응답을 확인합니다. 학생끼리는 위치를 볼 수 없으며 정답은 학생 응답에 포함하지 않습니다.
9. 제한시간 만료 또는 교사 조기 종료로 제출과 위치 공유를 중지하고 순위를 발표합니다. 동점은 공동 순위이고 이동 속도는 점수에 반영하지 않습니다. 종료 전에 제출한 응답은 종료 후에도 승인할 수 있으며 대기 응답이 있으면 임시 순위라고 표시합니다.

## 저장·권한·종료 처리

- `006_exploration_games.sql`: 게임맵, 전용 포인트, 미션, 게임방, 방 미션 복사본, 학생, 응답, 요청 재시도 기록의 8개 테이블.
- 모든 테이블에 RLS를 켜고 anon/authenticated 접근을 막습니다. 동일 출처·CSRF와 기존 서버 세션을 거쳐 `app_backend`로만 접근합니다.
- 교사의 제작 권한은 원본 지도 개설자·활성 관리자인 Google 계정에 연결됩니다. 방 진행·학생 위치 조회·응답 승인은 그 방을 연 교사만 가능합니다.
- 요청 UUID와 플레이어·미션 고유 제약으로 재시도 및 중복 점수를 막습니다. 동시 제출은 방 행을 잠가 직렬화합니다. 미션 편집과 응답 승인은 버전 검사로 충돌을 감지합니다.
- 서버가 최근 45초 이내 좌표, 미래 시간 허용 한도 10초, 위치 오차, 미션 반경을 검사합니다. 위치 이력 대신 학생별 마지막 좌표 하나만 저장합니다.
- 위치 공유 끄기·종료에서 좌표를 즉시 지웁니다. 화면이 숨겨지면 공유 중지 요청을 보내고, 돌아와서는 학생이 다시 켜야 합니다.
- `npm run db:schedule-games`: `aimap-game-expiry` 작업이 매분 만료 방을 종료하고 90초 이상 오래된 좌표를 지웁니다. 브라우저가 없어도 실행됩니다. 방 종료 판정은 API에서도 수행하므로 분 단위 작업을 기다려 새 제출을 허용하지 않습니다.
- 원본 지도 보관·삭제 시 게임 운영을 중지합니다. 원본 지도 30일 복구 기간 후 영구 정리에서 연결된 게임 자료도 외래키로 정리합니다. 종료한 방의 점수와 응답은 결과 확인을 위해 유지합니다.

## 실행 및 검증

```sh
npm run db:migrate
npm run db:schedule-games
npm run typecheck
npm test
npm run db:check-schema
npm run build
```

- 전체 자동 검사 62개 통과. 탐험게임 신규 10개에는 실제 SQL 마이그레이션을 실행하는 PGlite 서비스 통합 검증이 포함됩니다.
- 신규 검증: 유형·동의 입력, GPS 거리·시각·오차, 동점 순위, 게시 포인트 복사, 권한, 미션 방 복사본 고정, 정답·타 학생 위치 비노출, 인원·시도 제한, 재시도 점수, 시간 만료, 승인·중복 승인, 공유 중지, 오래된 위치 정리, 원본 보관·영구 정리 연계.
- 로컬 실제 HTTP 검증: `scripts/check-game-room.mjs`로 가상 학생 두 명 참여 → 교사 브라우저 시작 → 퀴즈 자동 100점 → 관찰 승인 대기 0점 → 브라우저 교사 승인 150점 → 종료 순위 250점·0점 및 위치 삭제를 확인했습니다. 실제 사용자 쿠키와 GPS는 읽지 않습니다.
- 교사 화면에서 신규 포인트·이모지·검색 위치·미션·반경·제한시간·방 코드·시작·승인·조기 종료를 직접 실행했습니다. 390px 및 320px 화면의 폭 넘침을 검사합니다.

## 실제 기기에서 남은 확인

- 실제 Android 야외 이동, 위치 권한 거부·재허용, GPS 오차와 통신 변동은 현장 확인이 필요합니다. 가상 좌표 검증을 실제 이동 검증으로 간주하지 않습니다.
- 브라우저가 열려 있는 동안 위치를 공유합니다. 화면을 끄거나 다른 앱으로 이동할 때 지속적으로 추적하는 기능은 제공하지 않습니다.
- 브라우저가 보내는 위치는 서버에서 신선도·반경을 검사하지만 위치 조작을 완전히 방지할 수는 없습니다. 수업 활동용 검증 범위입니다.
- 사진 업로드 미션은 이번 범위에 추가하지 않았습니다. 위치에 도착해 퀴즈, 관찰 응답, 체크리스트를 제출합니다.
