# 기상청 날씨지도 설정

## 인증키 발급

1. [기상청 API허브](https://apihub.kma.go.kr/)에서 회원가입합니다.
2. 휴대전화 연락처 인증을 완료하고 로그인합니다.
3. 지상관측 → 종관기상관측(ASOS)에서 **시간자료**와 **일자료(기간 조회)**의 ‘API 활용신청’을 완료합니다. 사용하는 주소는 `kma_sfctm2.php`, `kma_sfcdd3.php`입니다.
4. 지상관측 → 지상관측 지점정보에서 **지상(SFC)**의 ‘API 활용신청’을 완료합니다. 주소는 `stn_inf.php`입니다. 이 API가 승인 대기나 장애 상태이면 앱은 기상청 공개 관측지점 이력 목록을 사용하고 출처·확보일을 표시합니다.
5. 마이페이지에서 인증키를 확인합니다.
6. 이 프로젝트의 `.env.local`에 아래 값을 직접 입력합니다.

```dotenv
KMA_API_KEY=발급받은_인증키
```

이 키는 **기상청 API허브**의 키입니다. 공공데이터포털의 `ServiceKey`와 다릅니다. 채팅, Git, 스크린샷에 키를 공유하지 않습니다. `NEXT_PUBLIC_` 접두어를 붙이지 않습니다.

키를 저장한 뒤 개발 서버를 다시 시작합니다. 운영 배포에는 Vercel 프로젝트의 Settings → Environment Variables에 같은 이름으로 저장하고 재배포해야 합니다.

API허브는 무료 API를 제공합니다. 현재 이용 절차와 호출 한도는 [공식 이용안내](https://apihub.kma.go.kr/apiInfo.do)를 확인합니다. 이 앱의 키는 서버에서만 사용합니다.

API 항목은 [종관기상관측 안내](https://apihub.kma.go.kr/apiList.do?apiSeq=2)와 [지상관측 지점정보 안내](https://apihub.kma.go.kr/apiList.do?seqApi=2&seqApiSub=317)에서 확인할 수 있습니다.

## 지도에서 제공하는 자료

- 기존 ‘날씨생활’ 지도는 학생이 생활 속 날씨 흔적을 기록하는 지도입니다.
- 새 ‘기상청 날씨’ 지도는 기상청 관측자료를 조회하며, ‘우리 관찰 기록’으로 전환하면 기존 기록 기능을 사용할 수 있습니다.
- 전국 시·도, 시·군·구, 읍·면·동을 선택합니다. 행정구역 위치와 가장 가까운 관측소의 값을 **대표 자료**로 사용합니다.
- 관측소 이름과 거리를 함께 표시합니다. 인접한 동은 같은 관측소를 사용할 수 있습니다. 동에서 각각 측정한 값이나 지역 전체의 면적 평균이 아닙니다.
- 관측소 정보 API를 사용할 수 없으면 기상청 기상자료개방포털의 공개 ASOS 이력에서 기준일의 이름·좌표를 선택합니다. 포함된 자료의 출처와 갱신 방법은 `src/lib/weather-station-data/README.md`에 있습니다.
- 과거 일자료와 현재 관측자료를 구분합니다. 현재 관측값은 하루 전체의 통계가 아닙니다.
- 기온·강수량·습도·풍속과 날씨 종류별 일수를 사용자가 선택해 봅니다. 종류별 일수는 관련 관측자료가 있는 경우에만 표시합니다.
- 관측하지 못했거나 제공하지 않는 값은 결측으로 표시합니다. 결측을 0이나 맑음으로 바꾸지 않습니다.

## 문화유산지도

문화유산, 옛 건물, 전통 기술, 생활문화와 지역 이야기를 기록합니다. GPS는 필수가 아닙니다. 큰 지도에서 위치를 누르거나 카카오 장소 검색 결과의 이름·주소를 보고 선택합니다. 현재 위치 버튼은 선택 사항입니다.

역사적 사실과 구전 이야기를 구분하고, 시대·지정 정보·출처를 아는 만큼 입력합니다. 기존 지도와 같이 사진, 설명, 링크, 댓글, 분석·제안 기능을 사용합니다.

## 운영 확인

인증키가 없으면 설정 안내를 표시하며 관측자료를 만들어 표시하지 않습니다. 실제 연결 검증에는 유효한 인증키가 필요합니다. 키를 추가한 환경에서 지역별 조회, 일·주·월 집계, 결측, 현재 관측시각, 지도 표시와 그래프를 확인합니다.

### 키 입력 후 활용신청 오류가 표시될 때

기상청에서 HTTP 403과 ‘활용신청이 필요한 API’라는 응답을 받으면 키 발급만으로는 해당 API를 사용할 수 없는 상태입니다. 위 세 항목을 각각 신청하고 마이페이지의 신청·승인 상태를 확인합니다. 승인된 API 이름과 실제 호출 주소가 일치해야 합니다.

관측자료 API는 `WEATHER_PERMISSION_REQUIRED` 안내로 표시합니다. 관측소 정보 API만 사용할 수 없으면 공식 공개 이력으로 보완합니다. 키나 기상청 응답 원문은 사용자 화면에 전달하지 않습니다. 승인 후 같은 조건으로 다시 조회해 실제 자료 수신을 확인합니다.

로컬과 배포 환경의 실제 연결은 다음 명령으로 검사합니다. 이 검사는 지도·기록을 변경하지 않습니다.

```shell
node scripts/check-live-weather.mjs http://localhost:3001
node scripts/check-live-weather.mjs https://ai-town-map.vercel.app
```
