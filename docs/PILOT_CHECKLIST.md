# 모두의 지도 — 휴대전화 파일럿 기록지

대상: https://ai-town-map.vercel.app/ · 작성일: 2026-09-29

학교 모임 1팀과 일반 커뮤니티 1팀에서 각각 수행한다. 처음에는 테스트임을 표시한 초대 전용 지도를 사용한다. 학생 실명·얼굴·차량번호·집 주소 대신 별칭과 식별 정보 없는 사진을 사용한다. 실제 위험에 접근하는 조사는 하지 않는다.

## 기기와 역할

| 항목 | 기입 |
|---|---|
| 실행일 / 배포 커밋 | |
| 모임 유형 / 진행자 별칭 | |
| 기기 A: 개설자 / OS / 브라우저 버전 | |
| 기기 B: 초대 참여자 / OS / 브라우저 버전 | |
| 회선: Wi-Fi / 4G / 기타 | |
| 조사 주제 / 지도 ID | |

Android Chrome과 iOS Safari에서 각각 수행하고, 가능하면 최신 및 직전 주요 버전을 포함한다. 비밀번호·키·초대 코드는 이 기록지에 적지 않는다.

## 핵심 과업

각 항목은 통과 / 실패 / 미실행으로 기록한다. 실패하면 단계·기대 결과·실제 결과·기기·발생 시각을 적는다.

| 순서 | 실행 | 통과 기준 | 결과 |
|---|---|---|---|
| 1 | A에서 Google 로그인, 주제 선택·미리보기·초대 전용 지도 생성 | 선택 주제의 분류·평가·이모지만 표시 | |
| 2 | A에서 초대, B의 독립 브라우저에서 코드·닉네임 입장 | A의 Google 계정 없이 지도에 참여 | |
| 3 | B에서 위치 권한 거부 후 장소 검색, 핀 수동 조정 | 권한 허용 없이 다음 입력 단계 진행 | |
| 4 | 별도 시도에서 B가 직접 위치 권한 허용 | 예상 오차와 핀 확인 후 ‘이 위치 사용’으로 확정 | |
| 5 | 제목·설명·대체 이모지·링크·평가/질문·사진 입력 | 입력과 저장 결과 일치, 키보드로 제출 버튼 접근 가능 | |
| 6 | A에서 B의 기록 검수·승인 | 승인 전 공개 방문자에게 미노출, 승인 후 지도·분석에 반영 | |
| 7 | 같은 위치에 다른 기록 1건 추가 | 핀의 선택 목록에서 두 기록을 각각 열 수 있음 | |
| 8 | 댓글 작성·수정·신고, A가 숨김 | 본인만 수정, 숨긴 댓글은 일반 참여자에게 미노출 | |
| 9 | 기간·유형·평가·지도 영역 필터 적용 | 지도·목록·분석의 건수 일치, 없는 기록은 0건 | |
| 10 | 제안서 작성·검토 요청·확정·공유·PDF 저장 | 근거와 수치 확인, 권한 없는 브라우저에서는 비공개 자료 차단 | |
| 11 | 더보기의 지도 링크를 복사해 새 탭에 붙여넣기 | 홈 대신 해당 지도 열림. 비참여자는 초대 전용 지도 접근 불가 | |
| 12 | 개인정보 없는 큰 촬영 사진 / JPG / HEIC 각각 시도 | 성공 또는 이해 가능한 실패·재시도, 본문 유지·중복 없음 | |
| 13 | 저장 직전 회선 끊기→실패→연결 복구→재시도 | 입력 유지, 같은 제출 중복 없음. 새로고침하지 않고 검사 | |
| 14 | A에서 B 차단 후 B 제출 시도 | 서버 거절, 입력 유실 없이 안내 | |
| 15 | 기기 화면 회전·키보드 열기·확대 | 필수 입력·닫기·제출·지도 출처 접근 가능 | |
| 16 | VoiceOver/TalkBack으로 목록→상세→닫기→기록 양식 | 의미가 읽히고 뒤 화면으로 초점이 새지 않음 | |

네 기본 주제별로 기록·분석을 반복한다. 생태에는 종합평가와 제안 메뉴가 없어야 하고, 날씨생활에는 유형 색상과 생활 영향 평가가 구분되어야 한다. 직접 만들기는 단일색·분류색·평가색을 각각 확인한다. 실제 위치 권한은 테스트 담당자가 직접 선택한다.

## 측정과 피드백

- 주요 UI를 사용할 수 있기까지 걸린 시간과 지도 타일 준비 시간을 분리해서 기록한다. 4G 성능 목표는 UI 3초다.
- API 지연은 충분한 반복 표본과 실패 수를 함께 기록한다. p95 목표는 1초이며 한 번 빠르게 열렸다는 이유로 통과하지 않는다.
- 과업 완료 여부, 도움 요청 횟수, 이해되지 않은 문구, 눌리지 않은 버튼, 사진 실패 형식/크기를 적는다.
- 담당자의 계정·초대 코드·개인정보가 포함된 화면을 피드백에 첨부하지 않는다.
