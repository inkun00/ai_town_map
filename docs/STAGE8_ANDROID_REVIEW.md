# Android 15 가상 기기 검증 (2026-09-30)

대상은 배포 앱 `https://ai-town-map.vercel.app/`의 공개 화면이다. Pixel 7 프로필의 Android 15(API 35) Google Play 시스템 이미지와 Android Chrome을 사용했다. Google 계정에 로그인하지 않았으며 운영 지도·기록을 새로 작성하거나 수정하지 않았다. 이 검사는 이전의 데스크톱 모바일 뷰포트 검사와 달리 Android OS/Chrome에서 실행했지만, **물리적 휴대전화 검사는 아니다**.

| 항목 | Android Chrome에서 확인한 결과 |
| --- | --- |
| 홈 | 첫 화면의 지도 탐색·로그인·초대 진입, 주제 선택과 하단 탭이 390px 폭에서 보임 |
| 공개 지도 | 공개 지도 목록에서 지도를 열었고 Kakao 지도 타일·출처·범례·평가별 0건이 표시됨 |
| 지도/목록 | 지도에서 목록으로 전환, 빈 목록 안내 확인 |
| 분석 | 게시 기록 0건과 주제별 유형을 표시. 필터 패널을 펼쳐 유형·평가·기간 컨트롤을 확인 |
| 비로그인 작성 | 기록 탭을 누르면 해당 지도에 새 기록을 남길 수 없다는 안내 표시 |
| 홈 검색 | 이름 `1111` 입력 후 해당 공개 지도 1건이 목록에 남음 |
| 초대 진입 | 초대 코드·닉네임·제출 버튼과 7일 세션 안내가 한 화면에 보임. Android 화면 키보드 표시 중에도 닉네임 입력과 제출 버튼이 노출됨 |

이 지도의 게시 기록은 0건이어서 기존 핀 선택·사진·상세는 확인하지 못했다. 초대 코드가 없는 비로그인 에뮬레이터였으므로 기록 등록, GPS 거부/허용, 카메라·사진, 승인·댓글·제안서, 독립 기기 참여는 실행하지 않았다. TalkBack·실제 회전·4G/회선 단절도 아직 확인하지 않았다. 에뮬레이터의 Gboard는 떠 있는 키보드 형태로 표시돼 일반 휴대전화의 키보드 크기·동작을 대표하지 않을 수 있다.

실기기 파일럿은 [기록지](PILOT_CHECKLIST.md)의 결과 칸을 계속 비워 둔다. 두 사용자군의 Android 휴대전화에서 권한·촬영·보조기술·통신 복구를 직접 실행한 뒤 각 항목을 판정한다.
