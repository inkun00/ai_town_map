# 개인 지도 도구 · 2026-10-01

## 기능과 사용 흐름

등록된 지도 핀을 누르면 그 포인트의 작은 도구 팝업을 연다. 전역 도구 탭 메뉴는 제거했다. 상단에는 표시 개수·조건·범례·목록만 둔다. 실제 카카오 지도, 하단 현재 위치 이동, 주제별 이모지·평가 의미를 유지한다.

| 기능 | 동작 |
|---|---|
| 표시 | 상단 `👁️ 표시`에서 전체·보임·숨김 개수와 종류·이모지·개별 표시 스위치. 겹친 포인트도 각각 센다. |
| 반경 | 핀 팝업의 `반경` 선택 → 해당 핀에서 드래그 → 실시간 원·미터 표시 → 손을 떼면 저장. 1~20,000m의 연속 거리, 최대 12곳. 같은 중심의 새 반경은 기존 반경을 교체한다. 팝업에서 지운다. |
| 연결 | 핀 팝업의 `연결` 선택 → 해당 핀에서 드래그 → 실시간 직선·거리 표시. 다른 핀 가까이에서 초록 테두리와 `연결 준비` 안내 → 손을 떼면 두 핀의 연결선 저장. 빈 곳이나 지도 밖에서 놓으면 취소. 최대 100개, 역방향 중복·자기 자신 연결 방지. 출발점을 바꿔도 이전 선의 끝에서 자동으로 이어 붙이지 않는다. |
| 메모 | 핀 팝업의 `메모`에서 120자 텍스트·이모지·4가지 색상을 입력하고 지도에서 배치. 지도 메모 자체를 눌러 내용·위치 수정 및 삭제. 최대 100개. |
| 저장·공유 | 핀 팝업의 `저장·공유` 또는 표시 설정 하단에서 JSON 저장·불러오기. 사용자·지도별 기기 자동 저장과 파일 미리보기 유지. |

드래그 시작은 선택한 핀의 몸통·꼬리 주변으로 제한한다. 원본 포인트의 좌표는 움직이지 않는다. Pointer Events와 pointer capture로 마우스·터치·펜을 동일하게 처리한다. 도구가 선택되면 지도 이동·확대를 잠시 멈추고, 완료·취소·화면 이탈·크기 변경 후 기존 설정으로 복원한다. 취소 버튼과 Escape, 브라우저 pointercancel을 처리한다. 드래그 대신 미터 입력 또는 연결 대상 선택을 쓸 수 있다.

스냅은 CSS 픽셀 기준 진입 32px·이탈 44px이며, 근처에 더 가까운 핀이 있으면 대상으로 전환한다. 숨긴 포인트·조회할 수 없는 포인트·화면 밖 포인트는 연결 대상으로 잡지 않는다. 원·선의 임시 오버레이는 드래그 중에만 존재하고 개인 상태에는 손을 뗀 뒤에만 반영한다.

반경·연결선·메모의 그림 레이어도 각각 숨길 수 있다. 표시 스위치는 지도 핀에 적용되며 기록 목록·분석·내보내기·제안서의 데이터 집합을 변경하지 않는다. 숨긴 기록에는 목록에 `지도에서 숨김`을 표시한다. 필터는 기존의 서버 조회 조건이고, 도구의 표시 스위치와 별개다.

## 저장과 공유 범위

- 계정·게스트는 기존 세션 API의 안정적인 principal 해시(`draftScope`)로 로컬 저장 영역을 분리한다. 비로그인 공개 지도 열람자는 이 브라우저의 방문자 영역을 사용한다. 별도의 서버 저장·자동 기기 동기화·공개 공유 링크를 만들지 않는다.
- 사용자가 변경하기 전에는 초기 기본 상태로 기존 저장 내용을 덮어쓰지 않는다. 저장 실패 시 안내를 표시하고 파일 저장을 제공한다.
- 공유 파일에는 지도 ID, 포인트 참조 ID, 숨김 설정, 반경 거리, 연결점 쌍(기존 파일의 연결 순서 포함), 작성한 메모 내용·좌표·색상이 들어간다. 계정 해시·토큰·사진·원래 관찰 본문·작성자 정보는 내보내지 않는다.
- 앱이 파일을 다른 사람에게 자동 전송하지 않는다. 사용자가 직접 전달한다. 파일을 가진 것만으로 지도 접근 권한이 생기지 않는다.
- 불러오기는 2MB 이하, 형식·버전·같은 지도 여부·좌표 범위·반경 거리 범위·개수·메모 식별자 중복을 확인한 뒤 미리보기를 제공한다. 적용은 기존 개인 도구 설정을 교체한다. 바꾸기 전에 파일로 기존 설정을 보관할 수 있다.
- 반경과 연결선은 현재 조회·접근할 수 있는 포인트에만 의존한다. 누락된 연결점의 양옆을 자동으로 잇지 않으며, 합계에는 확인 가능한 구간만 포함한다. 필터나 포인트 변경 시 최신 좌표를 사용한다.
- 텍스트 오버레이는 DOM의 `textContent`로 생성한다. 가져온 HTML 문자열을 실행하지 않는다.

## 거리의 의미

카카오 `Circle`의 반지름 단위는 미터다. 연결선은 Haversine 계산과 평균 지구 반지름 6,371,008.8m를 사용한 대략적인 지표면 직선 거리이며 도로 경로·보행 거리·보행 시간은 계산하지 않는다. UI에서 직선 거리임을 명시한다.

SDK 근거: [Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events), [pointer capture](https://developer.mozilla.org/en-US/docs/Web/API/Element/setPointerCapture), [Kakao Web API Circle·Polyline·CustomOverlay·setBounds](https://apis.map.kakao.com/web/documentation/).

## 검증

- 자동 테스트 52개, TypeScript 검사와 프로덕션 빌드 통과.
- 임의 출발점의 독립적인 연결, 역방향 중복 방지, 누락점 단절, 화면 픽셀 스냅·대상 전환, 연속 반경, 기존 JSON 파일의 연결 순서 호환성 검사.
- 실제 Kakao SDK와 가상 공개 지도·포인트 3개로 검사. 반경 드래그 580m, A→B 142m 및 C→A 284m의 독립 연결, 빈 공간 놓기 취소, Escape 취소 후 지도 이동 복원 확인.
- 표시 개수 3/3→0/3, 지도 메모 배치·메모 직접 선택 편집, 공유 JSON 다운로드·미리보기·적용, 새로고침 후 반경·독립 연결선·메모 복원 확인.
- 390×844·320×740 화면에서 팝업과 버튼 배치 확인. 거리 오버레이가 핀 선택을 막지 않도록 핀을 위에 배치하고 거리 텍스트의 포인터 입력을 차단했다.
- 모바일 터치 이벤트 처리를 구현했으며 브라우저에서는 실제 좌표 드래그로 검사했다. 안드로이드 실기기 터치 검사는 별도다.

기존 기록은 수정하지 않는다. 시험 데이터는 아래의 전용 가상 데이터로 생성·정리한다.

재현용 가상 데이터: `RUN_MAP_TOOLS_UI=1`, `LIVE_APP_ORIGIN=http://localhost:3001` 환경으로 `node scripts/check-map-tools-ui.mjs` 실행. 검사 후 같은 환경에서 `node scripts/check-map-tools-ui.mjs cleanup` 실행. 기존 로컬 환경 파일의 연결 정보를 사용하며 출력에는 인증 정보가 포함되지 않는다. 가상 데이터만 정확한 소유자 식별자로 정리한다.
