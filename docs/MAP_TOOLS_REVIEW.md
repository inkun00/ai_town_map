# 개인 지도 도구 · 2026-10-01

## 기능과 사용 흐름

입장한 지도의 상단 `🧰 도구`를 누르면 표시·반경·연결·메모·저장·공유 패널을 연다. 실제 카카오 지도, 현재 위치 이동, 주제별 이모지·평가 의미는 유지한다.

| 도구 | 동작 |
|---|---|
| 표시 | 현재 조회 조건의 전체·보임·숨김 개수. 종류·사용된 이모지·개별 포인트의 표시 스위치, 모두 보이기·숨기기. 세 조건이 모두 켜져야 핀이 표시된다. 겹친 포인트도 각각 센다. |
| 반경 | 포인트를 목록이나 지도에서 선택. 50·100·250·500·1,000·2,000m를 복수 선택해 원과 거리 이름을 표시. 최대 12곳. 기존 반경 수정·삭제. 큰 반경을 볼 수 있도록 지도 범위 조정. |
| 연결 | 포인트를 선택한 순서대로 연결. 최대 50회 선택. 구간 거리·합산 직선 거리·순서 번호. 되돌리기·전체 지우기·전체 보기. 출발점으로 되돌아오는 연결도 허용. |
| 메모 | 120자 텍스트, 이모지 또는 둘 다 지도 위에 추가. 기존 이모지 검색 목록 재사용, 4가지 배경색. 최대 100개. 내용 수정·위치 변경·위치 보기·삭제. |
| 저장·공유 | 같은 기기의 브라우저에 사용자·지도별 자동 저장. 도구 설정의 JSON 파일을 다운로드해 직접 전달. 동일 지도의 접근 권한이 있는 사용자가 파일 미리보기 후 자신의 도구에 적용. 다른 기기로도 파일을 옮길 수 있다. |

반경·연결선·메모의 그림 레이어도 각각 숨길 수 있다. 표시 스위치는 지도 핀에 적용되며 기록 목록·분석·내보내기·제안서의 데이터 집합을 변경하지 않는다. 숨긴 기록에는 목록에 `지도에서 숨김`을 표시한다. 필터는 기존의 서버 조회 조건이고, 도구의 표시 스위치와 별개다.

## 저장과 공유 범위

- 계정·게스트는 기존 세션 API의 안정적인 principal 해시(`draftScope`)로 로컬 저장 영역을 분리한다. 비로그인 공개 지도 열람자는 이 브라우저의 방문자 영역을 사용한다. 별도의 서버 저장·자동 기기 동기화·공개 공유 링크를 만들지 않는다.
- 사용자가 변경하기 전에는 초기 기본 상태로 기존 저장 내용을 덮어쓰지 않는다. 저장 실패 시 안내를 표시하고 파일 저장을 제공한다.
- 공유 파일에는 지도 ID, 포인트 참조 ID, 숨김 설정, 반경 거리, 연결 순서, 작성한 메모 내용·좌표·색상이 들어간다. 계정 해시·토큰·사진·원래 관찰 본문·작성자 정보는 내보내지 않는다.
- 앱이 파일을 다른 사람에게 자동 전송하지 않는다. 사용자가 직접 전달한다. 파일을 가진 것만으로 지도 접근 권한이 생기지 않는다.
- 불러오기는 2MB 이하, 형식·버전·같은 지도 여부·좌표 범위·선택 가능한 거리·개수·메모 식별자 중복을 확인한 뒤 미리보기를 제공한다. 적용은 기존 개인 도구 설정을 교체한다. 바꾸기 전에 파일로 기존 설정을 보관할 수 있다.
- 반경과 연결선은 현재 조회·접근할 수 있는 포인트에만 의존한다. 누락된 연결점의 양옆을 자동으로 잇지 않으며, 합계에는 확인 가능한 구간만 포함한다. 필터나 포인트 변경 시 최신 좌표를 사용한다.
- 텍스트 오버레이는 DOM의 `textContent`로 생성한다. 가져온 HTML 문자열을 실행하지 않는다.

## 거리의 의미

카카오 `Circle`의 반지름 단위는 미터다. 연결선은 Haversine 계산과 평균 지구 반지름 6,371,008.8m를 사용한 대략적인 지표면 직선 거리이며 도로 경로·보행 거리·보행 시간은 계산하지 않는다. UI에서 직선 거리임을 명시한다.

SDK 근거: [Kakao Web API Circle·Polyline·CustomOverlay·setBounds](https://apis.map.kakao.com/web/documentation/).

## 검증

- 자동 테스트 49개 통과. 추가 6개는 가시성 결합·거리 기준값·누락점 단절·개인 영역 분리·공유 왕복·잘못된 파일·큰 숨김 목록을 검사한다.
- TypeScript 검사와 프로덕션 빌드 통과.
- 실제 Kakao SDK를 사용한 가상 공개 지도 1개와 포인트 3개로 브라우저 검사. 기존 이용자의 기록을 수정하지 않았다.
- 종류·이모지·개별 포인트 스위치에서 개수 변화와 실제 마커 제거 확인. 모두 숨겨도 통계 3건과 기록 목록을 유지.
- 100m·500m 복수 원, 2km 원의 범위 조정, 지도 핀 직접 선택으로 반경 중심 지정 확인. 거리가 없으면 반경 등록 비활성화.
- A→B→C 각 구간 약 142m, 합계 284m 확인. 지도 핀으로 C→A를 추가하면 568m로 변경. 마지막 선택 취소와 전체 보기 확인.
- 지도 빈 공간에서 메모 생성, 내용 수정·삭제, 메모 레이어 숨김 확인. `<b>우리 모임</b>`를 입력해 태그가 실행되지 않고 문자로 표시되는 것을 확인.
- 공유 JSON이 실제 Downloads에 저장됨을 확인. 파일 선택→미리보기→적용으로 삭제했던 연결선·메모 복원. 새로고침 후 원·연결선·메모 자동 복원.
- 390×844와 320×740 화면 너비·버튼 배치 확인. 콘솔 오류 없음.

재현용 가상 데이터: `RUN_MAP_TOOLS_UI=1`, `LIVE_APP_ORIGIN=http://localhost:3001` 환경으로 `node scripts/check-map-tools-ui.mjs` 실행. 검사 후 같은 환경에서 `node scripts/check-map-tools-ui.mjs cleanup` 실행. 기존 로컬 환경 파일의 연결 정보를 사용하며 출력에는 인증 정보가 포함되지 않는다. 가상 데이터만 정확한 소유자 식별자로 정리한다.
