# 5단계 진행 검토 — 댓글·검수·운영

작성일: 2026-09-29

## 구현

- 게시 기록의 평면 댓글 작성·조회·본인 수정·삭제, 관리자 숨김·복구. 지도별 댓글 사용 여부와 활성 멤버 권한을 서버에서 검사한다.
- 참여자의 기록·댓글 신고와 관리자 신고함·처리 사유 기록. 같은 참여자의 동일 대상 미처리 중복 신고를 막는다. 댓글은 10분에 10개, 신고는 1시간에 5개로 제한한다.
- 승인형 지도의 대기 기록 승인, 기록 숨김·수정 요청·복구. 공개 목록은 게시 기록만 조회하고 작성자 목록·관리자 검수함은 별도 범위로 조회한다. 숨김 기록의 본문·좌표·사진은 작성자에게 재노출하지 않고, 관리자 검수함에서는 사진과 내용을 확인할 수 있다.
- 지도 공개·참여·검수·댓글 설정, 참여자 차단·복구, Google 계정 참여자 관리자 지정·해제. 소유자 전용 변경과 관리자 권한을 구분하고 서버에서 매번 현재 멤버십을 확인한다.
- 지도 보관·재개와 지도·기록의 soft delete·30일 이내 복구. 삭제한 지도는 소유자 전용 목록에서 보관 상태로 복구할 수 있다. 변경 이력은 `app.audit_events`에 기록한다.
- 모바일 상세 기록에 댓글·신고·숨김·삭제, 더보기 화면에 내 기록·검수함·신고함·참여자·설정 화면을 연결했다. 새 지도 만들기에서 참여·승인·댓글 기본값을 선택할 수 있다.

## 검증

- `003_community_moderation.sql`을 Supabase DB에 적용했다. 기존 지도·기록은 유지했다.
- `npm run typecheck`, `npm run build`, `npm test` 통과.
- `RUN_LIVE_PHASE5=1 node scripts/check-live-phase5.mjs` 통과. 합성 계정과 지도를 만들어 승인 전 기록·사진 비공개, 댓글 중복 요청·버전 충돌·숨김·삭제, 신고·관리자 처리, 비참여자·차단 멤버 쓰기 거부, 지도 공개→초대 전용 전환, 지도·기록 복구를 확인했다. 합성 자료는 검사 후 삭제했다.

## 남은 확인과 운영 과제

- 모바일 실제 기기의 GPS 허용·거부, 지도 터치·군집, 사진 선택, Google 개설자와 초대 게스트의 화면 흐름을 확인해야 한다. 4단계 실사용 검증도 이 항목에 포함된다.
- 목록 API의 cursor 페이지네이션과 관리자 신고 이력 전체 화면은 후속 보완이다. 현재 댓글·신고·멤버·검수 목록에는 각각 상한이 있다.
- soft delete 복구 기한이 지난 콘텐츠를 정리하는 운영 작업은 아직 자동화되지 않았다. 30일 이후 복구 API는 거부하지만 DB 자료는 남아 있으므로 보관·삭제 정책을 확정하고 정리 작업을 추가해야 한다.
- 통계·CSV·제안서 저장은 6단계 범위다. 현재 분석·제안 화면은 임시 UI다.
