# 모두의 지도 — 개발 단계와 모델 사용 계획

작성일: 2026-09-29 · 기준: PRD 1.3 · 현재 상태: 7단계 자동·브라우저 통합 검증 및 주요 수정, 실기기와 일부 인수 기준 대기

## 1. 진행 원칙

사용자 요청에 따라 **다음 개발 단계에 들어가기 전에 작업 범위·권장 GPT 모델·추천 이유·완료 기준을 먼저 안내한다.** 같은 단계 안에서도 작업 성격이 달라져 모델 변경이 유리하면 해당 작업 전에 알린다.

각 단계가 끝나면 실제 산출물, 확인한 결과, 미해결 사항을 기록한다. 완료 기준을 만족하지 못하면 다음 단계에 완료된 것으로 넘기지 않는다. 모델 안내는 사전 고지이며 매번 별도의 승인을 요구하는 절차는 아니다. 사용자가 모델 변경을 요청하거나 직접 변경 중이면 이를 반영한다.

모델을 추천한 것과 실제 실행 모델이 바뀐 것을 구분한다. 현재 대화의 모델을 자동으로 전환했다고 주장하지 않는다. 변경이 필요할 때 사용자가 선택할 모델명과 추론 수준을 안내한다. 모델 선택만을 위해 새 채팅이나 하위 에이전트를 만들지 않는다.

## 2. 모델 선정 기준

OpenAI 공식 문서는 GPT-6 Astra를 복잡한 추론·코딩, GPT-6 Sol을 성능과 비용의 균형, GPT-6 Luna를 범위가 명확하고 반복적인 작업에 적합한 모델로 안내한다. 아래 단계 배정과 추론 수준은 이 프로젝트의 의존성·오류 영향도를 고려한 권장안이며 모델 간 성능을 직접 측정한 결과는 아니다. [공식 모델 안내](https://developers.openai.com/api/docs/models), [GPT-6 사용 가이드](https://developers.openai.com/api/docs/guides/latest-model)

| 모델 | 프로젝트 내 권장 용도 | 기본 추론 수준 |
|---|---|---|
| GPT-6 Astra (`gpt-6-astra`) | 전체 구조 설계, 주제별 설정·권한의 복합 조건, 원인 불명 버그, 최종 통합 검토 | High |
| GPT-6 Sol (`gpt-6-sol`) | 일상적인 기능 구현, 모바일 UI, 지도 연동, API·데이터 처리, 검증·수정 | High, 단순 작업은 Medium |
| GPT-6 Luna (`gpt-6-luna`) | 확정된 규칙의 이모지 목록·예시 데이터 정리, 짧은 문구·문서·국소 스타일 수정 | Medium |

기본 개발 모델은 **Sol**, 설계와 중요한 검토에는 **Astra**, 작고 독립적인 정리에는 **Luna**를 권장한다. 단순 수정마다 모델을 바꾸지는 않는다. 권한·인증·데이터 삭제·통계 정확성에 영향을 주는 변경은 범위가 작아도 Sol 또는 Astra로 처리한다.

사용 가능한 모델과 추론 옵션은 실제 앱의 선택 목록을 확인한다. 위 API 문서의 비용 정보가 Codex 구독 사용량과 동일하다고 가정하지 않는다. 이 문서는 개발을 돕는 모델 선택 계획이며, 앱에 탑재할 AI 분석 모델은 후속 단계에서 별도로 평가한다.

## 3. 개발 단계

0단계 요구사항 작성, 1단계 기술·데이터 설계, 2단계 모바일 UX 시안을 완료했다. 3단계의 실제 Supabase DB 연결, Google 로그인, 지도 생성, 독립 클라이언트의 초대·권한 격리를 검증했고 물리적 다른 기기와 운영 설정 검증이 남았다. [1단계 완료 검토](STAGE1_REVIEW.md), [2단계 완료 검토](STAGE2_REVIEW.md), [3단계 검토](STAGE3_REVIEW.md)에 산출물과 남은 항목을 기록했다.

| 단계 | 작업 성격과 범위 | 권장 모델·추론 | 산출물과 완료 기준 |
|---|---|---|---|
| 1. 기술·데이터 설계 | 프레임워크·저장소·인증 선택, 지도별 권한, 주제별 기능 설정, 이모지·평가 데이터 구조, API 계약 | **Astra · High** | 기술 설계서·스키마·권한표. 생태는 평가 없이 저장되고 모든 지도는 이모지를 가지며, 비공개 자료의 접근 경계가 정의됨 |
| 2. 모바일 UX와 화면 골격 | 주제 선택, 지도·목록, 등록 단계, 상세·분석·제안 화면, 바텀시트·이모지 선택 UI | **Sol · High** | 샘플 데이터로 조작 가능한 화면. 주요 모바일 크기에서 주제별 입력·메뉴 차이와 이모지 표시를 확인 |
| 3. 계정·지도·참여 기반 | 프로젝트 설정, DB·API, 개설자 로그인, 초대 코드·게스트 세션, 지도 생성·주제 설정 저장 | **Sol · High**, 권한 검토는 **Astra · High** | 다른 기기의 초대 참여, 서버 권한 검사, 지도 간 데이터 격리 검증. 닉네임만으로 타인 기록 권한을 얻을 수 없음 |
| 4. 카카오맵·현장 기록 | 실제 지도, 위치 검색·GPS·수동 지정, 이모지 핀·군집, 주제별 양식, 사진·링크, 저장·수정·재시도 | **Sol · High** | 실제 지도에서 기록 생성·조회. 평가 미사용 지도 정상 동작, 이모지 일치, 위치 거부 대안과 중복 제출 방지 확인 |
| 5. 댓글·검수·운영 | 댓글, 신고, 승인·숨김, 참여자 관리, 공개 전환, 보관·삭제 흐름 | **Sol · High**, 공개 범위 검토는 **Astra · High** | 작성자·관리자·방문자별 접근 검증. 대기·숨김 기록과 비공개 사진이 노출되지 않음 |
| 6. 통계·수동 제안서 | 지도·목록·차트의 필터 일치, 평가 분모, CSV, 근거 연결, 제안서 저장·공유·인쇄 | **Sol · High** | 테스트 데이터의 예상 집계와 일치. 평가 없는 지도에 평가 통계가 생기지 않고 제안 기능을 끈 지도에 관련 UI가 나타나지 않음 |
| 7. 통합 검증·파일럿 준비 | PRD 인수 기준, 모바일 접근성, 위치·네트워크 오류, 개인정보·권한·성능 검토 | **Astra · High**, 개별 수정은 **Sol · High** | 인수 기준별 통과·미통과 기록, 주요 결함 해결, 학교·일반 커뮤니티 파일럿 수행 준비 |
| 8. 파일럿 개선·출시 | 실제 사용 피드백, 업로드·검색·API 사용량 점검, 호스팅·운영 설정, 복구 절차·최종 배포 | **Sol · High**, 복합 장애 분석은 **Astra · High** | 두 사용자군의 핵심 과업 검증, 운영 설정 확인, 배포 후 주요 흐름 점검 |

단계 번호 순으로 진행한다. 2단계의 샘플 데이터 화면은 실제 카카오맵·서버 연동 완료로 보고하지 않는다. 3~6단계에서 순차적으로 실제 데이터와 연결한다. 개발 기간은 인력·로그인 방식·호스팅·외부 서비스 준비 상태를 확인한 뒤 산정한다.

### 주제별 확인 사례

- 유니버설 디자인: ♿·🚪 등 이모지 + 편의 평가 3색, 5개 기본 평가항목, 제안 기능.
- 생태: 🌳·🐦·🦋 등 다양한 이모지 + 분류 색상, 종합평가 없이 기록·분석.
- 안전: 🚦·🚸·🧯 등 이모지 + 안전 평가, 위험 이유·검수·개선 제안.
- 날씨생활: ☀️·🌧️·🧊 등 이모지 + 날씨 유형 색상, 생활 영향 평가는 별도 표시.
- 직접 만들기: 분류별 이모지 필수, 평가 선택, 핀 모드와 활성 기능에 맞는 UI·서버 검증.

### 후속: AI 분석

MVP 출시 이후 별도 진행한다. 분석 데이터 최소화, 근거 연결, 오류·비용·검토 절차 설계에는 Astra · High, 구현에는 Sol · High를 권장한다. 실제 앱에서 호출할 모델은 대표 관찰 자료로 정확성·근거 일치·비용·지연을 비교한 뒤 결정한다. 개발용 모델을 그대로 서비스용 모델로 고정하지 않는다.

## 4. 단계 전환 안내 형식

각 단계 완료 보고에 다음 안내를 함께 남기고, 다음 단계 착수 전에 다시 필요한 정보만 짧게 알린다.

> 다음 단계: 1. 기술·데이터 설계
> 작업: 주제별 기능 설정, 공통 이모지, 게스트 참여 권한, DB·API 구조 설계
> 권장 모델: GPT-6 Astra / High
> 이유: 이후 화면·서버·통계가 공통으로 사용할 규칙과 권한 경계를 함께 정해야 하기 때문
> 완료 기준: 기술 설계서, 데이터 스키마, 권한표, API 계약 작성

단계 중 모델을 바꾸어야 할 상황은 ‘권한 예외가 여러 기능에 걸쳐 발견됨’, ‘재현은 되지만 원인을 특정하지 못하는 통합 버그’, ‘여러 단계의 설계를 함께 바꿔야 하는 요구 변경’ 등이다. 추천 이유를 구체적으로 알리고 현재 산출물·남은 작업을 남겨 이어서 작업할 수 있게 한다.
