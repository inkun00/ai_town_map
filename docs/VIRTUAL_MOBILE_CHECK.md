# 가상 모바일 흐름 검증

실행일: 2026-09-29 · 코드 기준: `9ab52a9`

사용자가 Android 사용을 알려준 뒤 가상 검증을 요청하여 실행했다. 환경은 인앱 브라우저의 360×800 화면, 로컬 앱과 실제 연결된 DB다. Android OS 에뮬레이터나 실제 Android Chrome에서 실행한 결과로 취급하지 않는다. Google 로그인은 기존 세션을 사용했다.

## 확인한 결과

| 검사 | 결과 |
|---|---|
| 새 지도 5단계 | 주제 선택→정보→주제 설정→참여 설정→미리보기→생성 통과 |
| 초대 전용 지도 | 테스트용 유니버설 디자인 지도 생성, 비로그인 지도 조회 404 확인 |
| 위치 검색 | GPS 요청 없이 ‘서울시청’ 검색 결과로 지도와 기록 위치 선택 |
| 기록 3단계 | 위치→관찰→첨부·확인 후 실제 저장 통과 |
| 대체 이모지 | 보행로 대표 ♿ 대신 🚶 선택, 미리보기·목록·상세 일치 |
| 평가·내용 | ‘조금 불편’, 본문, 5개 항목의 확인 못함/해당 없음, 개선 아이디어 저장·재조회 일치 |
| 사진 | 개인정보 없는 단색 JPG(1800×1200)를 파일 선택기로 첨부, 저장 후 사진 표시 확인. 재접속 후 1600×1067 이미지 로드 확인 |
| 링크 | 입력한 관련 링크가 상세에 동일하게 표시 |
| 분석 | 게시 기록 1건, 조금 불편 1건 100%, 질문별 유효 응답 0건 및 확인 못함/해당 없음 제외 수치 확인 |
| 데이터 유지 | 지도 ID가 포함된 URL로 다시 접속해 기록·사진·이모지·평가·본문 유지 확인 |
| 접근 경계 | 별도 비로그인 HTTP 요청에서 해당 지도·기록 목록·사진 모두 404 |
| 크기 변경 | 360×800에서 본문·상세 확인 및 가로 넘침 없음. 800×360에서 DOM 가로 넘침 없음·상세 높이 306px 확인. 실제 회전 센서·가상 키보드는 미검증 |

[저장된 기록 화면](qa/stage7-virtual-record.png)은 합성 사진·문구로 만든 검증 자료다. 테스트 지도는 ID·제목·기록 수와 제목을 확인한 후 복구 가능한 삭제 상태로 정리했다. 사용자 기존 지도와 계정은 변경하지 않았다. 브라우저 화면 크기 설정은 복원했다.

## 별도 확인이 필요한 항목

- 실제 GPS 정확도·권한 거부/허용, 휴대전화 카메라·갤러리·HEIC·대용량 사진.
- Android의 화면 키보드, TalkBack, 실제 회선 단절/복구와 성능.
- 실제 새 Google 로그인, 독립 물리 기기의 초대 참여, 시스템 클립보드와 PDF 저장.

GPS 값을 가짜로 주입하거나 Android 장치인 것처럼 결과를 보고하지 않았다. 이번 테스트는 핵심 입력·저장·조회 과업의 증거를 추가하며, [7단계 검토](STAGE7_REVIEW.md)의 미충족 설정 기능과 실기기 항목은 계속 남는다.
