# 기상청 ASOS 관측지점 이력

- 출처: 기상청 국가기후데이터센터 [관측지점정보](https://data.kma.go.kr/tmeta/stn/selectStnList.do?pgmNo=123), 종관기상관측 분류 `SFC01`의 공개 CSV.
- 이용 조건: [공공데이터포털 데이터 15043574](https://www.data.go.kr/data/15043574/fileData.do)에 명시된 공공누리 제1유형(출처표시).
- `source.json`에 조회일, 정확한 다운로드 주소, 원본 파일 SHA-256, 가공 내역을 보존한다. 이 파일은 실시간 API 응답이 아닌 공개 메타데이터의 조회일 기준 사본이다.
- `asos-history.json` 각 행은 `[지점번호, 시작일, 종료일 또는 null, 지점명, 위도, 경도]`이다. 날짜는 `YYYY-MM-DD`, 좌표는 WGS84이다. 기상 관측값은 포함하지 않는다.
- 원본의 시작·종료일과 좌표를 그대로 보존한다. 종료일이 없는 행은 계속 운영 중인 이력이다. 동일 날짜에 이전 이력이 끝나고 다음 이력이 시작하면 더 최근 시작한 행을 선택한다. 시작 전·종료 후의 지점 좌표를 다른 날짜에 소급하거나 연장하지 않는다.
- 과거 조회는 해당 기준일에 유효한 지점 이력을 선택한다. 지점 운영 여부는 모든 기상 변수의 실측자료가 존재한다는 뜻이 아니다. 실측자료 유무는 별도로 확인해야 한다.
- 2026-10-18 사본은 105개 지점의 이력 148행이며, 그날 유효한 97개 지점은 당일 ASOS 시간자료가 제공한 97개 지점과 모두 일치한다.
- 갱신: 프로젝트 루트에서 `node src/lib/weather-station-data/refresh.mjs` 실행. 공식 CSV만 읽으며 인증키는 사용하지 않는다. 변경된 출처·행 수·좌표와 테스트를 검토한 후 배포한다.
